Privacy

This page explains the current data practices of the public Buddy Bootz website. It is provided as an informational privacy notice, not legal advice.

Newsletter / Waitlist

When you join the River Crew, the site sends the email address you submit to the configured form-processing service so the waitlist can be maintained. The current site uses Formspree for that submission flow.

Site Analytics

The public homepage currently loads Google Analytics to measure site usage. Analytics can involve browser/device information and usage events. You can use browser privacy controls or extensions to limit analytics collection.

Authentication

The repository is a static GitHub Pages site. No passwords or authentication tokens are stored in the public site code. A future private/admin area will require an external identity or access provider so that authentication can be enforced outside the public HTML.

Contact

For privacy questions or requests, use the contact method published by the Buddy Bootz project rather than sending credentials or other sensitive information through a public form.
